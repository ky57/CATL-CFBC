> 时间：2026-11-16（Asia/Singapore）

> 正式路径：`Z:\CATL\CATL-CFBC-InfoDB` = `/srv/sw-file/CATL/CATL-CFBC-InfoDB`

## 1. 这次改了什么（功能）

### 旧流程
1. 页面上直接点 L1–L6  
2. 再选维修物品（功率板 / ACDC / …）并弹数量  
3. 填故障原因

### 新流程
1. **先选维修物品**（表单第 01 步，标题是「维修物品」，不是「干什么」）  
2. **弹出「选择位置」**（交互和数量弹窗一样）  
3. 再弹出「选择数量」  
4. 填故障原因并保存

### 不同物品的位置选项

| 维修物品 | 位置怎么选 | 存进数据库的 `line` 示例 |
| --- | --- | --- |
| **堆垛机维修**（新增默认分类） | L1–L6 + A面/B面 + 高温/常温 | `L1-A面-高温` |
| **功率板 / ACDC / DCDC / 中位机**（及自定义分类） | **先**选 L1–L6，选完后才出现 A面/B面；点面即确认 | `L2-A面` |

### 界面其它调整
- 去掉常驻的 L1–L6 格子；位置只在弹窗里选  
- 「干什么」已改回 **维修物品**  
- 右侧统计：「按位置」（L1–L6；旧数据里单独的 A面/B面仍会显示）、「按维修物品」  
- 汇总文案里「拉线」改为「位置」；归档表头同步为「位置」

### 后端 / 库
- 启动时若旧库没有「堆垛机维修」，会自动插到分类最前（**不删、不覆盖已有记录**）  
- `qty` 字段照旧；`line` 字段改为存完整位置字符串  
- 旧记录仍是纯 `L1`…`L6` 的，编辑保存时需按新规则重选位置

## 3. 你怎么跑（推荐：Windows 直接拷到 Z:）

### 方式 A：Z: 盘已映射（最快）

1. 在能访问 `Z:\CATL\CATL-CFBC-InfoDB` 的电脑上，打开本仓库或解压同步包  
2. PowerShell：

```powershell
# 进入含 app.py / static 的目录后执行：
powershell -ExecutionPolicy Bypass -File .\sync-to-server.ps1
# 默认目标就是 Z:\CATL\CATL-CFBC-InfoDB
```

或手动复制（同样只碰代码）：

```powershell
$src = "D:\path\to\catl-code-only"   # 改成你解压后的路径
$dst = "Z:\CATL\CATL-CFBC-InfoDB"
Copy-Item -Force "$src\app.py" "$dst\app.py"
Copy-Item -Force -Recurse "$src\static\*" "$dst\static\"
Copy-Item -Force "$src\scripts\daily_digest.py" "$dst\scripts\daily_digest.py"
Copy-Item -Force "$src\README.md" "$dst\README.md"
```

3. **重启 Linux 常驻服务**（正式写库的是服务器上的进程，只拷文件不够）：

```bash
ssh cxw@192.168.2.10
# 登录后：
RUNTIME=/var/lib/catl-cfbc/runtime
LOG=/var/lib/catl-cfbc/stdout.log
APP=/srv/sw-file/CATL/CATL-CFBC-InfoDB

# 停旧进程
PID=$(python3 -c "import json;print(json.load(open('$RUNTIME/server.json')).get('pid',''))" 2>/dev/null)
[ -n "$PID" ] && kill "$PID" 2>/dev/null; sleep 1; kill -9 "$PID" 2>/dev/null

cd "$APP"
nohup env CFBC_RUNTIME="$RUNTIME" python3 app.py --port 46995 --force >"$LOG" 2>&1 &
curl -s http://127.0.0.1:46995/api/health
ls -l data/cfbc_records.db   # 确认库文件还在、时间戳未被整体替换
```

### 方式 B：SSH 一键（需本机能连 192.168.2.10，并已装 sshpass）

```bash
cd catl-code-only          # 解压后的目录
export SSHPASS='你的密码'  # 不要把密码写进脚本、不要提交 git
bash sync-to-server.sh
```

脚本会：备份远程 `app.py`/`static` → 覆盖代码 → 重启 46995 服务 → **不碰 data/**
